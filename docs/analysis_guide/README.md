# 分析の読み方ガイド

このプロジェクトの分析の部分 (`customer_features` ができたあと、顧客セグメンテーションから施策の仮説まで) を、順番に説明する。
[dbt の読み方ガイド](../dbt_guide/README.md) の続きにあたる。dbt のガイドが「データをどう作ったか」なら、こちらは「そのデータで何を判断したか」。

分析は一直線には進んでいない。試してみて、うまくいかなかった理由を確かめ、方針を変える、を何度か繰り返している。
このガイドでは、**何を試し、何を見て、なぜ方針を変えたか**の流れを追う。結果の数字だけでなく、判断の理由を説明できることを目標にする。

## 章の構成

| 章 | 見るもの | 分かること |
|---|---|---|
| [1. 特徴量の選定](01_feature_selection.md) | ADR 007・008、notebook 02 | 特徴量の候補の分け方、NULL・分布・相関の見方、似た特徴量を 1 つに絞る理由、欠損がランダムでないときの扱い |
| [2. クラスタリングと方針転換](02_clustering.md) | ADR 009・010・011、notebook 03・04 | 対数変換と標準化、K-means の評価指標、「何で分かれたか」の確かめ方、0 / 1 の特徴量の罠、クラスタリングをやめてルールにした理由 |
| [3. セグメントの定義](03_segmentation.md) | ADR 011・012・013、notebook 05 | 分類に使う指標と比べる指標を分ける理由、区切り方の決め方、定義の見直し (リピーター) |
| [4. セグメント別の分析](04_segment_analysis.md) | notebook 06 | 集計の単位 (顧客 / 注文) で答えが変わること、分母の明示、時期の偏りをそろえる方法 (直接法)、事実・解釈・仮説の分け方 |
| [5. 再購入の分析と施策の仮説](05_repurchase.md) | notebook 07・08、report 7 章 | 観察期間のそろえ方、信頼区間、差の大きさの見積もり、施策の仮説と検証の設計 |

## 判断の流れ (全体)

```
customer_features (1 行 = 1 人、22 列)
  │
  ├─ 1. 特徴量を 8 つに絞る                       ADR 008
  │
  ├─ 2. K-means (8 つ全部)                        ADR 009, notebook 03
  │      → 0 / 1 の特徴量だけで分かれた。金額・時期は効いていない
  │
  │   K-means (リピーター・遅延経験者をフラグで外して、残りを連続値で)  ADR 010, notebook 04
  │      → はっきりした塊がなく、連続した分布を区切っただけ
  │
  │   方針転換: クラスタリングをやめ、ルールで分ける   ADR 011
  │
  ├─ 3. セグメントを 4 つに決める                 ADR 012, notebook 05
  │      → あとでリピーターの定義を見直す          ADR 013
  │
  ├─ 4. セグメントどうしで購入体験を比べる        notebook 06
  │      → セグメントより、購入した時期の影響が大きい
  │
  └─ 5. 再購入の分析                              notebook 07, 08
         → 初回の体験より、初回のカテゴリによる差が大きい
         → 施策の仮説と、A/B テストの設計 (report 7 章)
```

## 読み方

- 各章は、ADR (何を決めたか) と notebook (何を確かめたか) を並べて読む。ADR の数字は、notebook の出力から来ている。
- ADR は決定したあとに書き換えない。判断が変わったときは新しい ADR を足し、古い ADR のステータスに「〜で置き換え」と書く。そのため、**古い ADR にも、そのときの判断と理由が残っている**。方針転換の経緯は、ADR を番号順に読むと追える。
- notebook のコードは Python (pandas、scikit-learn)。各章で、よく出てくる書き方を説明する。

このプロジェクトに限らず、データ分析をするときの手順と、各段階で自分に問うことは [analysis_workflow.md](../analysis_workflow.md) にまとめている。
