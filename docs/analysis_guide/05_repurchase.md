## 定義を先に決める

再購入の分析では、言葉の定義があいまいだと数字の意味が変わる。[ADR 013](../decisions/013_repeat_customer_definition.md) で先に決めている。

| 言葉 | 定義 |
|---|---|
| 初回購入 | 顧客の最初の購入日の注文 |
| 同時購入 | 初回購入日と同じ日の注文。再購入とはみなさない |
| 再購入 | 初回購入日より後の日の注文 |
| 90 日以内の再購入率 | 初回購入から 90 日以内に再購入した顧客の割合 |

`repeat` (セグメント) と「90 日以内の再購入率」は別の指標として扱う。`repeat` は観察できる全期間で再購入したか、再購入率は決まった期間の中で再購入したか。

## 観察期間をそろえる

データは 2018-08-29 で終わる。2018-08-01 に初回購入した顧客は、28 日しか観察できない。この顧客が再購入していなくても、「再購入しなかった」のか「まだその時期が来ていない」のか分からない。

```
初回購入                                   基準日 (2018-08-29)
2017-05 ●──────────── 90 日 ────────────|──────────────────────────────|  90 日を観察できる
2018-08               ●─── 28 日 ───|                                     90 日を観察できない → 対象から外す
```

そこで、**初回購入日が基準日の 90 日以上前の顧客だけ**で再購入率を計算している。

90 日にした根拠も、データから出している。リピーターの、初回から次の購入までの日数は、中央値 74 日、75% 点 175 日。90 日で約半数、180 日で約 4 分の 3 の再購入を捉えられる。主な指標を 90 日、補足を 180 日にしている。

このような「観察できる期間が人によって違う」問題は、顧客の離脱や継続を分析するときに必ず出てくる。

## 信頼区間で、差が偶然かを見る

再購入率は 1% 前後と小さく、グループによっては人数も少ない。差が偶然の揺れかどうかを、95% 信頼区間で確かめている。

```python
rate = repurchased.mean()                    # 再購入率
n = len(repurchased)                         # 人数
se = np.sqrt(rate * (1 - rate) / n)          # 標準誤差
ci_low, ci_high = rate - 1.96 * se, rate + 1.96 * se
```

- 標準誤差: 割合の推定値の揺れの大きさ。人数 `n` が多いほど小さくなる。
- 1.96: 正規分布で、真ん中の 95% に入る範囲。
- 2 つのグループの信頼区間が重ならなければ、差は偶然とは考えにくい。重なっていれば、差があるとは言い切れない。

notebook 08 では、信頼区間の重なりは**目安**であって、正式な検定ではないとも書いている (全体の再購入率には、そのカテゴリ自身も含まれるため)。

顧客の少ないカテゴリは、再購入率が偶然大きく振れる。そのため、90 日を観察できる顧客が 1,000 人以上のカテゴリだけを個別に示し、ほかは `(other)` にまとめている。

## 時期をそろえた確認 (ここでも)

第 4 章と同じく、リピーターは初回購入が早い時期に偏っている。初回購入の月の構成をそろえる直接法を、ここでも使っている。

| | 調整前 | 調整後 |
|---|---:|---:|
| 初回の遅延率 (リピーター / 単発購入) | 5.1% / 6.9% | 5.7% / 6.9% |

調整後は差が小さくなった。一部は時期の違いによる差だった、ということ。

遅延の有無による再購入率の差についても、初回購入の四半期ごとに確かめた。6 つの四半期のうち 4 つでは遅延した顧客の方が低かったが、2017Q3 は逆だった。**全体の差が、どの時期でも同じように見られるか**を確かめている。

## 差の大きさを見積もる

notebook 07 の結果:

| 初回の配送 | 90 日以内の再購入率 |
|---|---:|
| 遅延なし | 1.32% |
| 遅延あり | 1.01% |

遅延した顧客の方が低い。では、遅延をなくせば再購入は増えるか。notebook 07 では、**仮に関連がそのまま因果関係だったとしても、影響はどれくらいか**を計算している。

```
遅延した顧客は、90 日を観察できる顧客の 約 7.6%
この人たちの再購入率が 1.01% → 1.32% になったとしても
全体の再購入率は 1.30% → 約 1.32% (0.02 ポイント) にしかならない
```

差が「ある」かどうかだけでなく、**改善したら全体がどれだけ動くか**を見積もると、施策の優先度を判断できる。ここから「再購入を増やす施策は、配送品質の改善とは別に考える」という仮説が出てくる。

## カテゴリの分析 (notebook 08)

- 90 日以内の再購入率は、初回購入のカテゴリによって 0.57% (`cool_stuff`) 〜 2.25% と、約 4 倍の差がある。
- 全体 (1.30%) との差がはっきりしているのは、`bed_bath_table` (1.97%、7,141 人) と、低い側の `computers_accessories` (0.84%)、`cool_stuff` (0.57%)。
- 大きいカテゴリどうしの差 (約 1.1 ポイント) は、配送の遅延による差 (0.31 ポイント) より大きい。
- 再購入で初回と同じカテゴリを買った顧客は 38.6%。同じカテゴリの再購入の方が早く起きる。

### 結果が、決め方に左右されないかを確かめる

notebook 08 では、2 つの頑健性の確認 (結論が、分析のやり方の細かい選択に左右されないかの確認) をしている。

| 気になる点 | 確認 | 結果 |
|---|---|---|
| 初回のカテゴリは 1 つ、再購入のカテゴリは集合で扱っている。再購入に複数のカテゴリがあると「同じカテゴリ」と判定されやすい | 複数のカテゴリを含む顧客 (86 人) を除いて集計し直す | ほとんど変わらない |
| 再購入までの日数は、観察期間が短い顧客ほど短い側に偏る | 観察期間をそろえて (180 日・365 日) 集計し直す | 「同じカテゴリの方が早い」傾向は変わらないが、日数の値は大きく変わる (78〜163 日) |

2 つ目から、「日数の値は目安とし、施策の根拠には傾向を使う」と決めている。**どの数字は信頼でき、どの数字は条件で変わるか**を分けている。

## 施策の仮説と、検証の設計 (report 7 章)

分析の結果から、施策の仮説を優先度つきで出している。

| 優先度 | 施策 | 根拠 |
|---|---|---|
| 高 | 初回購入後に、同じカテゴリの商品を案内する | 30 日以内の再購入の半分以上が同じカテゴリ |
| 高 | 購入後の経過に応じて、別のカテゴリを案内する | 再購入までが長いほど、別のカテゴリの割合が高い |
| 高 | `bed_bath_table` の顧客から試す | 顧客が多く、再購入率も高い |
| 中 | 配送品質の改善 | 再購入率ではなく、満足度の向上を目的とする |

このデータには施策を実施した記録がないので、効果は分からない。そのため、**効果をどう測るか (A/B テスト)** の設計まで書いて終えている。

- 顧客を無作為に「案内あり / なし」に分けて比べる。無作為に分けると、時期や顧客の属性の偏りが両方に同じように入るため、差を施策の効果とみなせる。ここまで直接法などで苦労して時期をそろえてきたことを、実験では最初から解決できる。
- 再購入率だけでなく、購入金額やクーポンのコストも追う。

## まとめ

```
問いを 1 つずつ立て、答えから次の問いを決める (体験 → カテゴリ)
定義を先に決める (初回・同時購入・再購入・観察期間)
観察期間をそろえる: 最近の顧客は再購入する時間がない → 観察できる顧客に絞る
  期間の長さは、再購入までの日数の分布から決める
信頼区間で、差が偶然かを見る。人数の少ないグループはまとめる
時期をそろえた確認、時期ごとの確認を繰り返す
差の大きさを見積もる: 改善したら全体がどれだけ動くか → 施策の優先度
頑健性の確認: 決め方を変えても結論が変わらないか。変わる数字は目安として扱う
効果は測れないので、検証の設計 (A/B テスト) まで書いて終える
```

## 確認の問い

- 再購入率を計算するときに、初回購入が 2018-07 の顧客を外したのはなぜか。
- 「初回の配送が遅延した顧客は、再購入率が低い」。だから配送を改善すれば再購入が増える、と言えるか。2 つの理由で答えられるか (因果関係、影響の大きさ)。
- 再購入までの日数の中央値 (別のカテゴリで 113 日) を、施策の根拠にしなかったのはなぜか。
- A/B テストにすると、直接法による調整が要らなくなるのはなぜか。
