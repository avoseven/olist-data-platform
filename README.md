# olist-data-platform
Olist Data Platform — ECデータ分析基盤の構築


## Data
| CSV                                 | ざっくり何のデータ？     |
| ----------------------------------- | -------------- |
| `customers`                         | 顧客情報           |
| `orders`                            | 注文情報・注文日時・配送日時 |
| `order_items`                       | 注文された商品・価格・送料  |
| `order_payments`                    | 支払い情報          |
| `order_reviews`                     | レビュー・評価        |
| `products`                          | 商品情報           |
| `sellers`                           | 販売者情報          |
| `geolocation`                       | 郵便番号・緯度経度      |
| `product_category_name_translation` | 商品カテゴリの英訳      |
